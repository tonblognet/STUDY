# Поступай

Trust-first веб-сервис для выбора программ российских вузов. Интерфейс отвечает на три вопроса: подхожу ли я, что сдавать и сколько стоит обучение. Неизвестные значения хранятся как `null`, имеют явный статус и никогда не заменяются нулём.

> «Поступай» — рабочее название. Перед использованием домена нужно отдельно проверить доступность и товарные знаки.

## Архитектура

- Next.js/Vinext, React 19, TypeScript, Tailwind CSS 4.
- Модульный монолит: публичные страницы, API, бизнес-логика и редакторский контур находятся в одном приложении.
- PostgreSQL + Prisma — целевая модель для программ, версий показателей и источников при отдельном серверном развёртывании. Пользователь сопоставляется со стабильным `platformUserId`; пароль для платформенного входа не хранится.
- Размещённая Sites-версия использует серверно подтверждённую личность пользователя и D1 для постоянных профилей ЕГЭ, избранного, сравнения и журнала синхронизации.
- `lib/admissions` содержит независимые от UI правила подбора и полноты; `lib/user-state` отделяет валидацию, объединение и хранение пользовательского состояния от интерфейса.
- `data-sources/universities` содержит десять адаптеров официальных ресурсов; общий загрузчик проверяет домен, `robots.txt`, ограничивает частоту и сохраняет SHA-256.
- `MetricValue` хранит версию каждого показателя, год, статус, точный источник и ссылку на предыдущую версию.

## Локальный запуск

Требования: Node.js 22+, pnpm 11+, Docker Desktop.

```bash
cp .env.example .env
docker compose up -d postgres redis mailpit
pnpm install
pnpm db:generate
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Сайт: `http://localhost:3000`. Mailpit: `http://localhost:8025`.

## Переменные окружения

Скопируйте `.env.example` в `.env`. Локальные параметры PostgreSQL совпадают с `docker-compose.yml`. Реальные секреты в репозитории отсутствуют. Для редакторской зоны задайте `POSTUPAI_ADMIN_EMAILS`. Боевые платежи остаются выключенными, пока не настроены параметры `TBANK_*`, фискализация и постоянное хранилище истории платежей.

## Вход и роли

На размещённой Sites-версии `/login` и `/register` используют вход, который обслуживает платформа. Приложение получает серверные заголовки идентичности и не принимает пользовательский пароль. `/admin` дополнительно проверяет адрес электронной почты по серверному allowlist `POSTUPAI_ADMIN_EMAILS`; пустой список никому не выдаёт редакторский доступ.

Старые демонстрационные API `/api/auth/login` и `/api/auth/register` возвращают `410 Gone` и не создают cookies.

## Сохранения пользователя

После входа `/api/user-state` сохраняет до восьми профилей ЕГЭ, избранные программы и сравнение в серверной базе Sites. При первом входе локальные записи безопасно объединяются с серверными по идентификатору и дате изменения. Запросы изменения проверяют платформенную личность, `Origin`, размер и структуру данных; неизвестные идентификаторы программ отбрасываются.

Без входа тот же интерфейс работает локально. Если сервер временно недоступен, изменения остаются на устройстве и пользователь видит предупреждение вместо ложного статуса успешной синхронизации.

## Платежи T-Банка

В `lib/payments/tbank.ts` реализованы подпись корневых параметров SHA-256 по правилам T-Банка, безопасная проверка уведомления и вызов `v2/Init`. Тест использует официальный пример токена.

`/api/checkout` открывает банковскую форму только когда пользователь вошёл, заданы `PAYMENT_PROVIDER=tbank` и `PAYMENTS_LIVE=true`, присутствуют параметры терминала и `TBANK_FISCALIZATION_READY=true`.

Webhook проверяет токен и терминал, но до подключения постоянной записи платежа отвечает `503`, чтобы банк повторил доставку. Это намеренная защита: подписка не выдаётся по клиентской кнопке и подтверждённый платёж не теряется молча.

## Официальные данные

Текущий публичный снимок содержит по одной вручную сверенной представительской программе для десяти вузов: НИУ ВШЭ, МАИ, МФТИ, НИТУ МИСИС, НИУ МЭИ, НИЯУ МИФИ, РУДН, РАНХиГС, МГУ и РЭУ им. Г. В. Плеханова. Это реальный, но неполный набор. У каждой опубликованной цифры есть официальный URL, год и статус; неподтверждённые поля помечены `not_published` или `pending_review`.

Кэш PDF ВШЭ и РУДН содержит контрольную сумму и метаданные. Страницы с таблицами были отрендерены и визуально проверены, чтобы не перепутать строки и столбцы. Полный отчёт формируется в `data-sources/reports/quality-report.json`.

### Команды сборщика

```bash
pnpm data:discover -- --university=hse
pnpm data:fetch -- --university=hse --year=2026
pnpm data:parse -- --university=hse --year=2026
pnpm data:validate -- --university=hse --year=2026
pnpm data:import -- --university=hse --year=2026 --dry-run
pnpm data:import -- --university=hse --year=2026
pnpm data:report
```

`data:import --dry-run` выполняет все проверки без изменения БД. Реальный импорт требует `DATABASE_URL`; повторный запуск пропускает неизменившиеся значения, а изменившиеся записывает новой версией.

Автоматические проверки включают официальный домен, обязательные метаданные, диапазоны баллов, целые неотрицательные места, неотрицательную стоимость и непревышение бюджета суммой конкурсных групп. Спорные значения не публикуются автоматически.

## Основные маршруты

- `/` — подбор по предметам и баллам без регистрации;
- `/programs` — каталог в виде сетки или таблицы;
- `/programs/[slug]` — три блока решения, история и происхождение данных;
- `/compare` — сравнение со sticky-заголовками и удалением программ;
- `/account` — несколько наборов ЕГЭ, статус синхронизации, перенос локальных данных после входа;
- `/admin` — защищённый allowlist-проверкой редакторский обзор;
- `/support` — проверенные каналы обращения и правила безопасной поддержки;
- `/methodology` — правила статусов, подбора и полноты;
- `/api/programs` — те же доверенные данные с метаданными источников.

## Проверка

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:integration
```

Unit- и компонентные тесты проверяют альтернативные предметы, минимальные баллы, ДВИ, устаревшие и отсутствующие данные, полноту, объединение локальных и серверных сохранений, десять адаптеров, каталог и страницу программы.

## Известные ограничения

- Первая очередь содержит одну программу на вуз, а не полный каталог и не выборку из десяти программ каждого вуза.
- Полная история 2023–2026 опубликована вузами не для всех показателей; отсутствующие годы остаются пустыми.
- Для РАНХиГС прямой PDF возвращал 404 при контрольной загрузке, поэтому его значения оставлены на ручной проверке и локальный кэш не создан.
- На размещённой Sites-версии каталог является проверенным статическим снимком; PostgreSQL используется при локальном/серверном развёртывании.
- Постоянные пользовательские сохранения на Sites используют D1; Prisma/PostgreSQL остаётся контуром отдельного серверного развёртывания и импорта каталога.
- Боевые платежи не включены: требуется договор эквайринга, фискализация и постоянная идемпотентная обработка webhook. Интерфейс не выдаёт демо-подписку.
- Отзывы, социальные функции, ML-прогноз, уведомления и PDF-экспорт намеренно не входят в эту итерацию.
