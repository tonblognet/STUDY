# Handoff текущего слоя

Этот файл обновляет исполнитель перед передачей ветки ревьюеру. После merge он остаётся краткой историей последнего слоя и заменяется данными следующего.

## Идентификация

- Слой: `00 — rebuild baseline`
- Ветка: `codex/layer-00-rebuild-baseline`
- Исполнитель: владелец текущего рабочего дерева + Codex
- Ревьюер: второй разработчик
- Статус: baseline проверен и готов к использованию как стартовая точка

## Что готово

- Полная пересборка приложения «Поступай».
- Каталоги программ и московских вузов, детальные страницы и официальные ссылки на источники.
- Подбор по ЕГЭ с фильтрами, объяснениями и сохранением профиля баллов.
- FAQ, поддержка, аккаунт, избранное, сравнение и трекер поступления.
- Административная очередь, auth/payment/data foundations, документация и тесты.
- Командный execution plan, PR/Issue templates и общие проектные Codex-навыки.

## Как проверить

```powershell
pnpm install --frozen-lockfile
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:integration
pnpm security:audit
pnpm dev
```

Последний baseline-run: форматирование, lint, typecheck, 49 unit/component-тестов, 4 integration-теста, production build на 154 страницы и dependency audit прошли успешно.

Проверить основные маршруты: `/`, `/programs`, `/match`, `/universities`, `/universities/gubkin`, `/compare`, `/faq`, `/support`, `/account`, `/admin`.

## Решения

- Работа идёт строго последовательно по слоям из `docs/EXECUTION_PLAN.md`.
- История чатов не является источником правды; все правила и решения хранятся в Git.
- Непроверенные сведения о поступлении не подменяются предположениями.
- Персональные Codex credentials, sessions, memories и plugin caches не синхронизируются через GitHub.

## Известные ограничения и следующий фокус

- Часть каталожных значений намеренно помечена как требующая официальной проверки.
- Production auth, billing, notifications и ingestion требуют дальнейшей реализации по отдельным слоям.
- Следующий слой после merge baseline: `01 — data foundation`.

## Фокус ревьюера

- Воспроизводимость запуска на чистом клоне.
- Отсутствие секретов и случайных локальных артефактов.
- Зелёные quality gates.
- Корректность ключевых публичных маршрутов на desktop/mobile.
