- Импорт пропускал новую версию метрики, если менялись locator, документ, дата проверки, проверяющий или редакторская заметка, но значение и URL оставались прежними.

## Что реализовано

- Добавлены отдельные 2026 adapters для МГТУ им. Баумана, МГИМО, Пироговского, Сеченовского, Губкинского университетов, МГЮА, РХТУ, РГГУ, Финансового университета и Московского Политеха.
- Реестр теперь покрывает каждый вуз публичного каталога и принимает программные источники только с официального домена соответствующего вуза.
- Pipeline останавливается при пропущенном, лишнем или дублирующемся адаптере.
- Добавлен regression-тест, сопоставляющий adapters со всеми университетами и основными URL всех 101 программ.
- `pnpm data:validate` теперь проходит для всего каталога без критических ошибок; неизвестные экзамены остаются предупреждениями и не подменяются предположениями.
- Quality snapshot регенерирован: 20 вузов, 101 программа, 1 387 sourced indicators, 0 конфликтов источников.
- Версионирование импорта теперь сравнивает не только значение, статус и URL, но также документ, страницу, лист, диапазон, секцию, даты получения и проверки, редактора, срок следующей проверки и заметку.
- Добавлены тесты, подтверждающие идемпотентность полностью одинакового импорта и создание новой версии при изменении provenance.
- Добавлена кроссплатформенная настройка Prettier `endOfLine: auto`, чтобы обязательный format gate одинаково работал на Windows и Unix checkout без массовой перезаписи файлов.
- Добавлен source-aware DTO для официального сайта, логотипа, адреса, числа общежитий, ВУЦ и адресов кампусов всех 20 вузов.
- Для каждого university fact сохраняются `sourceKind`, точный URL, год, дата получения и проверки, проверяющий, locator, срок следующей проверки, заметка и quality status.
- Создана версионная Prisma-модель `UniversityFactValue` и миграция; идентичный импорт пропускается, а изменение значения, типа источника или provenance создаёт новую версию.
- В денормализованные поля `University` и `Campus` при импорте попадают только значения со статусом `verified`; `pending_review` не публикуется как установленный факт.
- Подтверждены официальными страницами адреса основного кампуса МГТУ им. Баумана, МГИМО и Сеченовского университета; для Сеченовского также зафиксирована отдельная официальная страница логотипов.
- Quality snapshot теперь отдельно считает 111 university/campus indicators и содержит их точные `factSources`: всего 1 498 индикаторов, 254 verified, 147 pending review, 1 064 not published и 0 конфликтов.
