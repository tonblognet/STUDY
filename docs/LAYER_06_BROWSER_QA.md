# Браузерная проверка слоя 06

10 ноября 2026, сборка `CRojeHz8VR7PypulL6FTB`. Chrome через Playwright CLI,
1440×1000 и 390×844. По 24 успешные проверки на каждой ширине.

## Стенд и маршруты

Приложение `http://localhost:3220` из текущей production-сборки, выделенная
локальная PostgreSQL UTF8/UTC и отдельная случайная `operations_test_*` схема
на каждую ширину. Использованы синтетические owner, SUPPORT, ADMIN,
CONTENT_MANAGER и target accounts. Приватные cookie не включены в отчёт.
Preview каталога отдельно: `http://127.0.0.1:3100`, snapshot-режим.

| Маршрут                         | Проверено                                                                                                              |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `/account` → `/account/billing` | Навигация, пустая история, pending/confirmed, права, отзыв после возврата                                              |
| `/pricing`                      | Одна попытка, повтор после reload без второго Init, возобновление в новой вкладке из истории                           |
| `/support`                      | Нативная ошибка короткой темы, создание, история и ответы, сохранение черновика при 409, закрытие и повторное открытие |
| `/admin`, `/admin/support`      | Меню SUPPORT без финансов/ролей; ответ сотрудника и сохранение времени первого ответа                                  |
| `/admin/billing`                | Сверка, явное второе подтверждение суммы полного возврата, один Cancel и отзыв связанного доступа                      |
| `/admin/users`                  | Изменение роли и завершение старой сессии target                                                                       |
| `/admin/billing`, `/login`      | Редактор не получает финансовый UI; гость отправляется на вход                                                         |

Проверены горизонтальные границы всех основных состояний, видимый keyboard
focus, переносы карточек и сообщений. Снимки формы поддержки на обеих ширинах
просмотрены после исправления границ и размеров textarea. Loading/disabled
состояния предусмотрены компонентами; сетевые и конкурентные ошибки дополнены
HTTP/DB suite. Объёмная история платежей и сообщений проверена интеграционно,
а не объявляется отдельным браузерным сценарием.

## Результат и ограничения

Нет неожиданных HTTP-ответов, console errors или runtime errors. Единственный
ожидаемый 409 — устаревшая версия обращения; текст пользователя сохранён.
Результаты: `tmp/nov10-layer06-codex-browser-r6-1440-results.log` и
`tmp/nov10-layer06-codex-browser-r6-390-results.log`; снимки
`output/playwright/nov10-layer06-{1440,390}-*.png` остаются локальными QA-артефактами.
Обе временные схемы удалены, тестовый кластер остановлен.

Банковские запросы перехватывались только в изолированном тестовом child
через `tests/tbank-fetch-preload.mjs` и направлялись в loopback fixture.
Переход платёжной формы перехватывался browser context. Это проверяет нашу
логику, но не является банковским sandbox, реальным списанием, проверкой
кассы или совместимости терминала. Production не содержит флага подмены банка.
Реальная банковская приёмка остаётся незакрытым внешним критерием.
