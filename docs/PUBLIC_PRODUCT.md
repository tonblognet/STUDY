# Публичный продукт — слой 03

Слой объединяет каталог программ, каталог вузов, карточки, сравнение и подбор.
Данные приёма и расчёт слоя 02 остаются источником фактов; слой 03 меняет
пользовательский путь, доступность и представление результатов.

## Сохранение и переходы

- `/programs`, `/universities` и `/match` сохраняют публичные фильтры в
  `localStorage` под отдельными версионными ключами и в параметре `filters` URL.
- Явный `filters` или `q` из ссылки имеет приоритет перед сохранёнными значениями.
  Эти же фильтры применяются на сервере до гидратации. Обычный переход в каталог
  восстанавливает последний выбор в браузере.
- Изменение поля заменяет текущую запись истории, а не создаёт запись для каждой
  буквы. «Назад» из карточки возвращает URL с прежними фильтрами.
- Сброс очищает запрос, ограничения и количество показанных карточек.
  Строки, перечисления, числа и массивы проходят валидацию; повреждённые данные
  заменяются значениями по умолчанию. Неизвестные поля удаляются.
- URL содержит только публичные условия поиска. Баллы, имя профиля и результаты
  ДВИ туда не записываются. Профили ЕГЭ сохраняются существующей явной кнопкой;
  временный расчёт в панели каталога не является сохранённым профилем.
- При недоступном browser storage остаются состояние текущего сеанса и URL.
  Синхронизация фильтров между устройствами не входит в этот слой.
- Из карточки программы можно открыть вуз; из сравнения — добавить программы
  или перейти к проверке баллов. Неизвестные показатели сохраняют пояснения.

## Доступность и состояния

- Один `main` на странице, ссылка перехода к содержимому, заметный фокус,
  отступ прокрутки под закреплённую шапку.
- Фильтры имеют доступные названия. Скрытая мобильная панель исключена из
  клавиатурной навигации. Панели фильтров и ЕГЭ удерживают фокус, закрываются
  Escape и возвращают фокус на открывшую их кнопку.
- Категории подбора — обычные переключатели с `aria-pressed`; они не выдают себя
  за вкладки без соответствующего клавиатурного поведения.
- Счётчики сообщают результат через `role=status`, не перечитывая весь список.
  Сравнение имеет подпись таблицы, заголовки строк/колонок и область прокрутки.
  Первая колонка и заголовки закреплены внутри этой области; годы, значения и
  статусы разнесены, различия выделены жёлтой границей. На мобильном экране
  таблица прокручивается отдельно от страницы, в том числе клавишами стрелок.
- Общие компоненты загрузки, ошибки, отсутствующей страницы и пустого сравнения
  используют ту же типографику, кнопки и переход к каталогу.
- Сохранено предпочтение уменьшенной анимации. Контраст и читаемость мелких
  подписей проверяются на production-сборке вместе с основными маршрутами.

## Производительность и границы

Программы и результаты подбора показываются порциями по 24, при этом счётчик
отражает все найденные записи. Количество раскрытых программ каталога сохраняется
с фильтрами. Повторяющиеся ссылки в строках программ не запускают массовый
prefetch. В карточке МГУ конкурсные группы раскрываются порциями по 12,
поиск и выбор факультета работают по всем 85 группам. Для основных маршрутов
добавлены loading boundaries.

Это ограничивает объём DOM; каталог по-прежнему передаётся клиенту целиком для
локального поиска. Серверная пагинация и полевые Core Web Vitals не заявляются.
Замеры локального production preview не равны производительности production
под нагрузкой. Новые факты, миграции и изменения рабочей БД в слой не входят.

## Проверка

Контракты URL/storage покрыты unit-тестами; SSR-проверки проверяют фильтрацию
до гидратации и единственный основной landmark. Browser QA дополнительно
проверяет reload, back/forward, сброс, сравнение, панели, клавиатуру,
мобильное переполнение, контраст и runtime errors.
Окончательные маршруты, результаты и ограничения фиксируются в `HANDOFF.md`.
